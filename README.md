# Retail SQL Analysis — E-Commerce Business Intelligence

## Business Question
Where is this e-commerce business leaving money on the table — 
and which customers, products, and markets should it prioritize?

## Key Findings
- 84% of revenue concentrated in UK — dangerous single-market dependency
- EIRE and Netherlands customers spend 60x more per customer than UK — 
  wholesale buyers hiding inside retail data
- Revenue spikes 3x in October/November — entire business is seasonally driven
- 1,013 at-risk customers represent significant recoverable revenue
- Top 2 products reach similar revenue through opposite strategies — 
  volume vs. price

## SQL Techniques Used
CTEs, Window Functions (RANK, LAG, NTILE, SUM OVER),
RFM Segmentation, Date Functions, CASE statements,
Subqueries, REGEXP filtering

## Tools
MySQL, MySQL Workbench

## Dataset
Online Retail II — UCI Machine Learning Repository
